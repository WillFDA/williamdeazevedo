**Wix convient si vous voulez créer seul, vite, un petit site qui évoluera peu : l’hébergement et la maintenance sont inclus, mais le site reste lié à la plateforme et ne peut pas être déplacé ailleurs. WordPress convient si vous voulez un site qui vous appartient, que n’importe quel prestataire peut reprendre, à condition d’assurer les mises à jour. Un site sur mesure se justifie quand l’image, la vitesse et les demandes de contact comptent plus que l’outil : il faut alors exiger le code, les accès et un moyen de modifier vos contenus.**

Wix ou WordPress ? Posée comme ça, la question ressemble à un choix de logiciel. En réalité, vous choisissez surtout à qui appartiendra votre site dans trois ans, qui l’entretiendra, et ce qu’il deviendra le jour où vous voudrez changer de prestataire ou d’outil.

Je suis développeur web et designer freelance à Achères (78). Je ne vends ni Wix ni WordPress : je code des sites sur mesure, avec un outil d’édition quand le client veut modifier ses textes lui-même. Pour la troisième option, je suis donc juge et partie : je vous dirai aussi quand Wix ou WordPress conviennent mieux.

## Wix et WordPress : deux modèles différents, pas deux logiciels concurrents

On les compare souvent comme deux marques du même produit, alors que ce sont deux façons différentes d’avoir un site.

### Wix : vous louez une plateforme tout compris

Wix est un service en ligne : vous construisez votre site dans l’éditeur de Wix, et il est hébergé sur les serveurs de Wix. L’hébergement, la sécurité, le certificat HTTPS et les mises à jour du logiciel sont gérés par la plateforme. Son centre d’aide précise que le site doit être « hébergé et opéré sur les serveurs de Wix » pour fonctionner.

C’est le principe d’une location : tout est prêt, rien n’est à installer, mais le site vit chez Wix, avec ses règles.

### WordPress : un logiciel libre installé chez l’hébergeur de votre choix

WordPress est un logiciel libre, publié sous licence GPL : chacun peut l’utiliser, l’étudier, le modifier et le redistribuer. Selon WordPress.org, il fait tourner plus de 43 % des sites web. Vous l’installez (ou votre prestataire l’installe) chez l’hébergeur de votre choix, et vous pouvez le déplacer ailleurs plus tard.

Une précision pour éviter la confusion : WordPress.com est un service où l’hébergement est inclus, alors que WordPress.org distribue le logiciel à installer soi-même. Les deux utilisent le même WordPress ; la différence, c’est qui héberge. Ici, « WordPress » désigne la version installée chez un hébergeur.

## WordPress ou Wix : le comparatif en un tableau

Voici les deux outils face au site sur mesure, critère par critère :

| Critère | Wix | WordPress | Site sur mesure |
| --- | --- | --- | --- |
| Prise en main | Éditeur visuel, accessible sans connaissances techniques | Interface d’administration à apprendre, plus simple si le site est bien préparé | Vous ne construisez rien : vous validez les maquettes, puis vous modifiez vos contenus si un outil d’édition est prévu |
| Qui héberge | Wix, obligatoirement | L’hébergeur de votre choix | L’hébergeur choisi avec votre prestataire, à mettre à votre nom |
| Qui fait la maintenance | Wix pour la plateforme ; vous pour vos contenus | Vous, votre prestataire ou l’hébergeur : cœur, thème, extensions, PHP | Votre prestataire, avec moins d’éléments à mettre à jour |
| Propriété et export | Vos contenus vous appartiennent, mais le site ne peut pas être hébergé ailleurs | Le site entier peut être déplacé chez un autre hébergeur | Le code vous est livré si le contrat le prévoit |
| Design | Modèles personnalisables | Thèmes, ou thème développé pour vous | Conçu pour votre activité, sans modèle de départ |
| Vitesse sur mobile | Dépend du modèle, des images et des applications ajoutées | Dépend de l’hébergeur, du thème et des extensions | Dépend du travail du développeur : à exiger et à mesurer |
| Référencement (SEO) | Les réglages de base sont présents | Les réglages de base sont présents, souvent complétés par une extension | À exiger dès la conception |
| Ajout de fonctions | Applications de la plateforme | Très large choix d’extensions | Développées selon le besoin |
| Changement de prestataire | Vous l’invitez sur votre site Wix, ou il reconstruit le site ailleurs | Facile si vous avez les accès : WordPress est très répandu | Facile seulement si le code et la documentation sont livrés |
| Coûts | Un abonnement | Création si un prestataire s’en charge, puis hébergement, nom de domaine et maintenance | Création, puis hébergement, nom de domaine et maintenance |

Ce tableau ne donne aucun montant, car tout dépend du projet. Pour comparer des budgets réels, lisez [ce qui sépare deux niveaux d’offre](/articles/site-600-euros-vs-site-2000-euros/).

## Propriété : à qui appartient votre site si vous partez ?

### Le site, les contenus et le nom de domaine : trois choses différentes

Quand on parle de « mon site », on mélange souvent trois éléments :

- **les contenus** : vos textes, vos photos, votre logo, vos articles ;
- **le site lui-même** : la mise en page, le design, le code qui fait fonctionner l’ensemble ;
- **le nom de domaine** : votre adresse, par exemple `votreentreprise.fr`, qui pointe vers le site.

Avec **Wix**, le centre d’aide est clair sur les deux premiers points : « le contenu que vous construisez sur Wix vous appartient », mais le site ne peut pas utiliser un autre hébergeur, car il repose sur la technologie propre à Wix. Changer d’outil veut donc dire reconstruire le site ailleurs. Le nom de domaine, lui, peut quitter Wix : un domaine acheté chez Wix se transfère vers un autre fournisseur, sauf dans les 60 jours qui suivent son achat ou une modification des coordonnées du titulaire. Il faut ensuite reconfigurer l’e-mail professionnel.

Avec **WordPress**, le logiciel peut tourner chez n’importe quel hébergeur. La documentation officielle explique comment déplacer un site WordPress vers un nouveau serveur, et l’outil d’export intégré produit un fichier avec les articles, les pages, les commentaires et les utilisateurs.

Avec un **site sur mesure**, tout dépend de ce qui a été prévu. Si le code vous est livré, avec les accès et une documentation, un autre développeur peut le reprendre. Sinon, vous dépendez d’une seule personne.

### Ce qu’il faut demander par écrit, quelle que soit l’option

Avant de signer, ou dès maintenant si votre site existe déjà :

- **le nom de domaine à votre nom**, ou à celui de votre entreprise, avec un accès au compte du fournisseur ;
- **vos accès à l’outil ou à l’hébergement** : compte Wix, administration WordPress, compte d’hébergement ;
- **une copie de vos contenus** : textes, images d’origine, logo.

Si votre prestataire actuel garde tout à son nom, l’article sur [le changement de prestataire web](/articles/changer-prestataire-web/) explique comment récupérer vos accès dans l’ordre.

## Référencement : Wix est-il moins bien placé sur Google que WordPress ?

Réponse courte : l’outil compte beaucoup moins qu’on le croit.

Dans son guide de démarrage en référencement, Google précise qu’avec un outil de gestion de contenu, vous n’aurez peut-être rien de technique à faire pour vos titres de pages, à part bien les rédiger : la plupart de ces outils peuvent les transformer eux-mêmes en balise lue par les moteurs. Wix comme WordPress savent produire des pages que Google peut lire.

Ce qui fait la différence se trouve ailleurs :

- **la structure** : une page par prestation, avec un titre clair, plutôt qu’une seule page qui parle de tout ;
- **les contenus** : vos métiers, votre zone d’intervention, vos réalisations, expliqués avec vos mots ;
- **la vitesse sur mobile** : des images trop lourdes ou trop d’applications ralentissent n’importe quel outil ;
- **votre fiche Google** et les avis clients, souvent décisifs pour une recherche locale.

Pour une entreprise qui travaille autour de chez elle, le [référencement local](/articles/seo-local/) pèse plus lourd que le choix entre Wix et WordPress. Et si votre site existe déjà, un [audit SEO](/articles/audit-seo/) montre ce qui bloque vraiment, quel que soit l’outil. Si votre site n’apparaît pas du tout sur Google, le problème vient d’ailleurs : voici [comment le vérifier](/articles/site-pas-sur-google/).

## Maintenance : qui s’en occupe, avec chaque option ?

**Avec Wix**, la plateforme se charge du logiciel, de l’hébergement et de la sécurité des serveurs. Il vous reste vos contenus, les applications que vous avez ajoutées, et l’abonnement à ne pas laisser expirer.

**Avec WordPress**, le cœur installe en général seul ses correctifs de sécurité, mais les versions majeures, le thème et les extensions doivent être tenus à jour, et la documentation officielle conseille de sauvegarder le site avant chaque mise à jour. Les mises à jour automatiques des thèmes et des extensions peuvent être activées, ce qui ne dispense pas de vérifier que le site fonctionne toujours.

**Avec un site sur mesure**, il y a en général moins d’éléments à mettre à jour, surtout si le site est statique. Le nom de domaine, l’hébergement, le certificat et le formulaire doivent quand même être suivis, par votre prestataire ou dans le cadre d’un contrat.

L’article sur la [maintenance de site web](/articles/maintenance-site-web/) compare en détail WordPress et le sur mesure.

### Un exemple : les failles critiques de PHP en octobre 2026

WordPress fonctionne avec PHP, un langage installé sur le serveur de l’hébergeur. Le 20 octobre 2026, [l’équipe de PHP a annoncé](https://www.php.net/archive/2026.php#2026-10-20-1) deux failles critiques, de gravité 9,2 sur 10. Selon [le CERT-FR](https://cert.cyber.gouv.fr/alerte/CERTFR-2026-ALE-014/), le centre d’alerte de l’État en cybersécurité, toutes les versions de PHP, de la 5 à la 8, étaient concernées. Les versions corrigées, [PHP 8.5.12, 8.4.27, 8.3.36 et 8.2.35](https://www.php.net/archive/2026.php#2026-10-21-5), sont sorties le 21 octobre. Les versions 8.1 et antérieures ne sont plus maintenues : le CERT-FR recommande de passer à une version maintenue et corrigée.

Ce que cela change, selon l’option :

- **WordPress** : mettre WordPress à jour ne suffit pas, PHP doit l’être aussi. Selon votre formule, cette mise à jour revient à l’hébergeur, à votre prestataire ou à vous : demandez qui s’en charge, et si votre version de PHP est encore maintenue.
- **Wix** : la plateforme gère ses serveurs, vous n’avez rien à mettre à jour.
- **Sur mesure** : tout dépend de la technologie. Un site statique hébergé sans PHP n’est pas concerné ; un site en PHP doit être mis à jour comme un WordPress.

## La troisième option : un site internet sur mesure, quand ça vaut le coup

WordPress ou Wix : la plupart des comparatifs s’arrêtent à ce duel. Il existe pourtant une troisième voie, le site internet sur mesure, conçu et codé pour votre activité, avec ou sans outil d’édition.

### Ce que ça change : design, vitesse, parcours de contact

Un site sur mesure ne part pas d’un modèle. Il part de votre offre : ce que vos clients cherchent, ce qui les rassure, et le chemin le plus court vers un appel ou une demande de devis. Le design reprend votre identité. Le code ne contient que ce qui sert, ce qui aide à garder un site rapide sur mobile.

Le site de [Le Fellic](/realisations/le-fellic/), une entreprise de maîtrise d’œuvre à Rennes, part ainsi de son offre : une page unique, construite autour du métier, des projets témoins, de la zone d’intervention et d’un formulaire de contact sécurisé.

### « Je veux pouvoir modifier mes textes » : sur mesure ne veut pas dire figé

Un site sur mesure peut être relié à un outil d’édition de contenus (un CMS), qui permet de modifier les textes, les photos ou les articles sans toucher au code.

Le site de [Persistance](/realisations/persistance/), un studio d’accompagnement graphique, fonctionne ainsi : la cliente peut publier elle-même ses articles, ses réalisations et ses témoignages, grâce au CMS Sanity.

### Les points à exiger : code livré, accès à votre nom, documentation

Le sur mesure n’a d’intérêt que s’il ne vous enferme pas chez votre développeur. Exigez par écrit :

- **le code livré**, dans un dépôt auquel vous avez accès ;
- **les comptes à votre nom** : nom de domaine, hébergement, outil d’édition ;
- **une documentation** suffisante pour qu’un autre professionnel reprenne le site.

Pour comparer les prestataires une fois l’option choisie, suivez le guide pour [choisir un développeur web](/articles/choisir-developpeur-web/).

## Quelle option selon votre situation ?

Il n’y a pas de meilleur outil dans l’absolu, seulement une option adaptée à votre situation :

| Votre situation | L’option adaptée | Pourquoi |
| --- | --- | --- |
| Vous testez une activité et vous voulez tout faire seul | Wix | Mise en ligne rapide, rien à installer, pas de mises à jour à gérer |
| Vous voulez publier souvent, garder la main et pouvoir changer de prestataire | WordPress | Autonomie sur les contenus, et de nombreux prestataires pour le reprendre |
| Vous êtes artisan ou TPE et vous attendez des demandes de devis, une image soignée et un site rapide | Sur mesure | Un site construit autour de votre offre et de votre parcours de contact |
| Vous avez déjà un Wix ou un WordPress qui ne vous apporte aucun contact | Audit, puis refonte | Comprendre ce qui bloque avant de changer d’outil |

Dans le dernier cas, changer d’outil ne règle rien si la structure et les contenus restent les mêmes. Commencez par un diagnostic, puis envisagez une [refonte de site internet](/refonte-site-internet/) si elle se justifie.

Enfin, pour une simple [page de campagne](/articles/landing-page/), un outil sans code peut suffire.

## Questions fréquentes

### Wix ou WordPress : lequel est le mieux pour le référencement Google ?

Ni l’un ni l’autre par principe : les deux produisent des pages que Google peut lire. Ce qui fait la différence, ce sont la structure du site, les contenus, la vitesse sur mobile et votre fiche Google.

### Peut-on passer d’un site Wix à WordPress (ou à un site sur mesure) sans tout perdre ?

Vos contenus vous appartiennent et votre nom de domaine peut être transféré, mais Wix indique que le site ne peut pas être hébergé ailleurs, ni ses articles de blog exportés vers une autre plateforme. Il faut donc reconstruire le site, en reprenant vos textes et vos images, et rediriger les anciennes adresses vers les nouvelles.

### Un site WordPress est-il forcément plus long à entretenir qu’un site Wix ?

Il demande plus de suivi, car le thème, les extensions et la version de PHP chez l’hébergeur doivent être mis à jour, alors que Wix gère la plateforme. Avec peu d’extensions, des sauvegardes régulières et un prestataire identifié, la maintenance reste raisonnable.

### Avec un site sur mesure, est-ce que je peux modifier mes textes moi-même ?

Oui, si un outil d’édition de contenus (un CMS) est prévu dès le départ. Vous modifiez alors vos textes, vos photos ou vos articles sans toucher au code. Précisez-le avant le devis.

### Le nom de domaine acheté chez Wix m’appartient-il ?

Vous pouvez le transférer vers un autre fournisseur, sauf dans les 60 jours qui suivent son achat ou une modification des coordonnées du titulaire. Le code de transfert est envoyé à l’adresse e-mail de ce titulaire : vérifiez dès maintenant que c’est la vôtre, ou celle de votre entreprise.

### Un site Wix fait-il moins professionnel aux yeux de mes clients ?

Pas en soi : vos clients jugent ce qu’ils voient, pas l’outil. Un site Wix soigné, avec votre nom de domaine, des textes clairs et de vraies photos, peut être très professionnel. Ce qui fait amateur, c’est un modèle laissé tel quel ou des informations dépassées.
